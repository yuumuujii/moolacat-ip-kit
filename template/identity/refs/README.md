# 垫图放这里（按 modes.json 里的顺序上传）

| 文件 | 作用 | 怎么得到 |
|---|---|---|
| `identity.png` | **身份图**：学脸、发型、配饰。正面头肩、纯白底、无文字 | 先用 prompt-base.txt 在任意生图工具里出几张，挑最满意的一张，之后永远不换 |
| `style/style-1.png`、`style-2.png` | **画风锚点**：学线条和上色质感，不学姿势 | 你已经认可的两张成品 |
| `chibi.png` | **Q 版身份图**：Q 版和长文插图用 | 用 chibi-prompt-base.txt + identity.png 生成，挑一张全身正面 |

建议：
- 垫图不要带文字、标注、箭头（模型会照着画进去）
- 配饰有左右之分的，所有垫图方向要一致
- 背景统一抠成纯白
